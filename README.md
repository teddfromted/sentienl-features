# Sentienl - Features & Commands Page

A sleek, modern features and commands showcase page for the **Sentienl** Discord bot, inspired by professional raid bot landing pages.

## 🎨 Design Features

- **Black & White Aesthetic**: Dark navy background with crisp white accents
- **Glowing Effects**: Smooth white glow animations on interactive elements
- **Responsive Layout**: Fully mobile-friendly design
- **Interactive Animations**: 
  - Hover effects on cards
  - Smooth scrolling
  - Mouse-proximity glow intensification
  - Fade-in animations as you scroll
  - Button ripple effects

## 📋 Sections

### Hero Section
- Centered glowing logo circle

## 🎯 Customization

### Update Bot Invite Link
Replace the bot client ID in both buttons:
```html
https://discord.com/oauth2/authorize?client_id=YOUR_CLIENT_ID
```

### Change Colors
Modify the color scheme in `styles.css`:
- Background: `linear-gradient(135deg, #0a0e27 0%, #1a1f3a 100%)`
- Accent Color: `#ffffff` (white)
- Replace with your preferred colors

### Add/Remove Commands
Edit the commands section in `index.html` to add or remove command cards.
